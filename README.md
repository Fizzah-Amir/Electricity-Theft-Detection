## Overview

Electricity theft is a critical problem in developing countries like Pakistan, causing massive financial losses to power distribution companies and destabilizing the electrical grid. Traditional manual inspection methods are slow, expensive, and inaccurate.

This project applies machine learning to automatically identify abnormal electricity consumption patterns in raw smart meter data — enabling automated, scalable, and real-time theft detection.

**Key challenges addressed:**
- Highly imbalanced data between normal and theft cases (handled with SMOTE)
- Noisy and irregular consumption patterns (handled in preprocessing)
- No ground-truth theft labels (synthetically injected using standard ETD methodology)

---

## Problem Statement

> Detect electricity theft by identifying abnormal electricity consumption patterns in raw smart meter data using machine learning techniques.

**Labels:**
| Label | Meaning |
|-------|---------|
| `0` | Normal user |
| `1` | Electricity theft (synthetically simulated) |

## Dataset

**Source:** [UCI Machine Learning Repository — Individual Household Electric Power Consumption](https://archive.ics.uci.edu/ml/datasets/individual+household+electric+power+consumption)

| Property | Detail |
|----------|--------|
| Type | Time-series (CSV) |
| Size | 2+ million records |
| Duration | December 2006 – November 2010 |
| Granularity | Minute-by-minute readings |

**Features:**

| Feature | Description |
|---------|-------------|
| `Date`, `Time` | Timestamp of reading |
| `Global_active_power` | Total active power consumed (kW) |
| `Global_reactive_power` | Reactive power (kW) |
| `Voltage` | Supply voltage (V) |
| `Global_intensity` | Current intensity (A) |
| `Sub_metering_1` | Kitchen appliances (Wh) |
| `Sub_metering_2` | Laundry appliances (Wh) |
| `Sub_metering_3` | Climate control (Wh) |

> **Note:** The dataset contains no theft labels. Theft cases are synthetically generated by injecting anomalous consumption patterns into normal data — a standard practice in electricity theft detection (ETD) research.

## Pipeline

```
Raw Dataset (UCI)
       │
       ▼
 Data Preprocessing
  ├── Handle missing values (forward-fill + interpolation)
  ├── Remove noise and outliers
  ├── Normalize consumption values
  ├── Aggregate to daily/weekly format
  └── Inject synthetic theft patterns
       │
       ▼
 Feature Engineering
  ├── Rolling average consumption
  ├── Peak vs. off-peak usage ratio
  ├── Consumption trend & deviation
  ├── Variance & standard deviation
  └── Hour-wise & day-wise behavior patterns
       │
       ▼
 Class Balancing (SMOTE)
       │
       ▼
 Model Training & Evaluation
  ├── Logistic Regression (baseline)
  ├── Decision Tree
  ├── Random Forest
  └── XGBoost
       │
       ▼
 Post-Processing
  ├── Flag suspicious users
  ├── Generate alert reports
  └── Visualize consumption patterns
       │
       ▼
 Output: Normal (0) / Theft Detected (1)
```

## Feature Engineering

| Feature | Description |
|---------|-------------|
| `rolling_mean_7d` | 7-day rolling average of active power |
| `peak_offpeak_ratio` | Ratio of peak-hour to off-peak consumption |
| `consumption_trend` | Linear trend slope over a window |
| `std_dev` | Standard deviation of daily consumption |
| `variance` | Variance of daily consumption |
| `hour_pattern` | Average consumption by hour of day |
| `day_pattern` | Average consumption by day of week |

---

## Models

| Model | Role |
|-------|------|
| Logistic Regression | Baseline classifier |
| Decision Tree | Interpretable rule-based model |
| Random Forest | Ensemble — robust to noise |
| XGBoost | Gradient boosting — best performance |

**Class imbalance** is handled using **SMOTE (Synthetic Minority Over-sampling Technique)** applied only to the training set to avoid data leakage.

**Evaluation metrics:** Accuracy · Precision · Recall · F1-Score · ROC-AUC · Confusion Matrix

## Setup & Usage

### 1. Clone the repository
```bash
git clone https://github.com/Fizzah-Amir/electricity-theft-detection
cd electricity-theft-detection
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Download the dataset
Download from the [UCI Repository](https://archive.ics.uci.edu/ml/datasets/individual+household+electric+power+consumption) and place `household_power_consumption.txt` in the project root.

### 4. Run the pipeline
```bash
# Step 1: Clean and preprocess data
python clean.py

# Step 2: Engineer features
python feature.py

# Step 3: Train models
python train.py

# Step 4: Evaluate on test set
python testing.py
```
